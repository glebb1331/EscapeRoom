# Архитектура проекта «Побег из комнаты» (Escape Room VR)

## 1. Общие сведения
- **Жанр:** кооперативный VR-квест (Escape Room).
- **Игроков:** 2–4 человека.
- **Платформа:** автономные VR-шлемы (Meta Quest 2/3, PICO 4).
- **Сеть:** локальная или облачная, UDP.

## 2. Топология
Выбрана топология **Dedicated Server**.

**Обоснование:**
- Сервер авторитетно хранит состояние мира: позиции игроков, предметы, таймер, прогресс.
- Клиенты отправляют команды ввода (движение, взять/передать предмет, нажать кнопку).
- Обеспечивает синхронность и защиту от читерства.

## 3. Распределение обязанностей

### Сервер
- `UdpServer` — приём/отправка пакетов.
- `WorldState` — состояние комнаты (игроки, предметы, таймер).
- `CommandHandler` — обработка команд.
- `Logger` — лог всех команд.

### Клиент
- `UdpClient` — сетевой обмен.
- `InputHandler` — ввод с контроллеров VR.
- `StateStore` — локальная копия состояния.
- `Renderer` — отображение аватаров, предметов, интерфейса.

## 4. Связь с ТЗ
- Асимметричная информация: сервер рассылает разным игрокам разные подсказки.
- Передача предметов: команда `TRANSFER_ITEM`, сервер обновляет владельца.
- Синхронные действия: сервер проверяет одновременность нажатия рычагов.
- Общий таймер: сервер хранит время, рассылает обновления.
